>>> This shows more information about a particular reward.

**Fields**:
`item`: desired reward. The `reward ID` can be found on the `/ticket rewards list`, or via autocomplete.

**Format**: `/ticket rewards inspect <reward>`

E.g. **/ticket rewards inspect 97979f9175a4b91f17d8a472**
This would display more information about the reward corresponding to 97979f9175a4b91f17d8a472.
